# Akshat Jain — Developer Portfolio

My personal portfolio website. It shows my technical skills, projects and contact details.

**Live site:** https://akshat505.github.io

## Sections
- **About:** introduction with a typing animation and links to my resume and social profiles
- **Technical Expertise:** Python, AI (models, LLMs, tools), Docker, SQL, HTML/CSS/JavaScript, MS Office
- **Projects:** [LegalGuard AI](https://github.com/akshat505/legalguard-ai), an Agentic AI System for Automated Software Development, and more
- **Contact:** a "Get in touch" form plus email, phone and LinkedIn

## Built with
- HTML5, CSS3 and JavaScript
- [Typed.js](https://github.com/mattboldt/typed.js) for the typing animation
- [Font Awesome](https://fontawesome.com/) for icons
- Responsive design with scroll animations and a mobile menu

## Run locally
Download or clone this repository and open `index.html` in any browser. No build step is needed.
